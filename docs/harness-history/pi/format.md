# Pi stored format

This describes the native session JSONL at the revision recorded in [README](README.md). Names below are literal stored JSON keys. TypeScript optional `undefined` values disappear under `JSON.stringify`; explicitly supplied JSON `null` values survive. The reader parses JSON without schema validation, so a declaration describes writer intent rather than a strict acceptance schema. Preserve unknown keys and unknown record types in raw capture. [Writer and reader](https://github.com/badlogic/pi-mono/blob/a4ccccbd64d4ccea1644f5a07bb94ef09075b219/packages/coding-agent/src/core/session-manager.ts#L617-L670), [append](https://github.com/badlogic/pi-mono/blob/a4ccccbd64d4ccea1644f5a07bb94ef09075b219/packages/coding-agent/src/core/session-manager.ts#L1173-L1224).

## File envelope and identities

| Record/field | Stored meaning |
| --- | --- |
| Header `type` | Literal `session` |
| Header `version` | New files write integer `3`; absent historical version means version 1 |
| Header `id` | Session ID. New defaults are UUIDv7; explicitly supplied safe IDs are allowed |
| Header `timestamp` | UTC ISO-8601 string generated by `new Date().toISOString()` |
| Header `cwd` | Working directory string; new session manager resolves its cwd |
| Header `parentSession` | Optional path string identifying the source file for a fork/extracted branch |
| Entry `type` | Discriminator listed below |
| Entry `id` | Native occurrence ID: normally first eight hexadecimal characters of a random UUID, collision checked within the session; full UUID fallback |
| Entry `parentId` | Previous active entry ID, or JSON `null` for a root |
| Entry `timestamp` | UTC ISO-8601 string recording append time |

Header is outside the entry tree. Session ID, entry ID, provider `responseId`, and tool-call `id` occupy distinct identity domains. Forks can copy entry IDs into a new session; scope entry identity to the captured source/session. Provider tool-call IDs may recur and require occurrence-aware pairing. [Declarations and generation](https://github.com/badlogic/pi-mono/blob/a4ccccbd64d4ccea1644f5a07bb94ef09075b219/packages/coding-agent/src/core/session-manager.ts#L43-L67), [IDs](https://github.com/badlogic/pi-mono/blob/a4ccccbd64d4ccea1644f5a07bb94ef09075b219/packages/coding-agent/src/core/session-manager.ts#L264-L284), [new header](https://github.com/badlogic/pi-mono/blob/a4ccccbd64d4ccea1644f5a07bb94ef09075b219/packages/coding-agent/src/core/session-manager.ts#L1058-L1083), [fork copies](https://github.com/badlogic/pi-mono/blob/a4ccccbd64d4ccea1644f5a07bb94ef09075b219/packages/coding-agent/src/core/session-manager.ts#L1826-L1881).

## Entry variants

Every variant includes the common entry fields above. `?` means optional/possibly omitted in writer output. Strings are not implicitly paths unless stated.

| `type` | Additional literal fields | Role in replay |
| --- | --- | --- |
| `message` | `message: AgentMessage` | One nested runtime message, including system messages |
| `thinking_level_change` | `thinkingLevel: string` | Updates branch thinking state |
| `model_change` | `provider: string`, `modelId: string` | Updates branch model state |
| `usage` | `kind: string`, `provider: string`, `model: string`, `usage: Usage`, `note?: string` | Attributed work such as `cache_warm`; no message contribution |
| `compaction` | `summary: string`, `firstKeptEntryId: string`, `tokensBefore: number`, `details?: unknown`, `usage?: Usage`, `fromHook?: boolean`, `systemMessage?: SystemMessage` | Summary plus retained context boundary and optional complete system/tool checkpoint |
| `branch_summary` | `fromId: string`, `summary: string`, `details?: unknown`, `usage?: Usage`, `fromHook?: boolean` | Summary of abandoned branch, attached at navigation destination |
| `custom` | `customType: string`, `data?: unknown` | Extension state; no direct context contribution |
| `custom_message` | `customType: string`, `content: string or text/image block array`, `details?: unknown`, `display: boolean` | Context-bearing custom message; `display` controls UI visibility |
| `context_edit` | `targetId: string`, `replacement: {content: string or content-block array} or null` | Latest retained edit replaces target content or omits target from effective context |
| `label` | `targetId: string`, `label?: string` | File-global bookmark; omitted/empty label clears it |
| `session_info` | `name?: string` | File-global latest display name; empty/missing clears it |

There is no persisted `leaf` record in this union. All records, including labels, custom state and usage, can become parents of subsequent records. `branch_summary.fromId` is the abandoned tip; `parentId` is the destination tip. When the abandoned tip is empty, the writer uses string `root` for `fromId`. `compaction.firstKeptEntryId` is inclusive; a writer request to retain no prior entry uses the compaction's own `id` as the boundary. `fromHook` distinguishes extension-generated summaries where supplied. `details` remains extension-owned. [Complete entry union](https://github.com/badlogic/pi-mono/blob/a4ccccbd64d4ccea1644f5a07bb94ef09075b219/packages/coding-agent/src/core/session-manager.ts#L69-L197), [compaction writer](https://github.com/badlogic/pi-mono/blob/a4ccccbd64d4ccea1644f5a07bb94ef09075b219/packages/coding-agent/src/core/session-manager.ts#L1271-L1297), [branch summary writer](https://github.com/badlogic/pi-mono/blob/a4ccccbd64d4ccea1644f5a07bb94ef09075b219/packages/coding-agent/src/core/session-manager.ts#L1606-L1635).

`context_edit` writer validates that its target exists on the active branch and is a `custom_message` or a user/assistant/tool-result `message`. String replacement for assistant/tool-result is stored as one text block. An edit retains the target's role, IDs, model, usage, timestamps and other metadata. A null replacement suppresses the entire contribution. Raw original content remains in the earlier record. [Writer checks](https://github.com/badlogic/pi-mono/blob/a4ccccbd64d4ccea1644f5a07bb94ef09075b219/packages/coding-agent/src/core/session-manager.ts#L1370-L1408), [projection](https://github.com/badlogic/pi-mono/blob/a4ccccbd64d4ccea1644f5a07bb94ef09075b219/packages/coding-agent/src/core/session-manager.ts#L519-L573).

## Nested messages and content blocks

Nested `message` uses Pi's provider-neutral runtime model, serialized directly. It is distinct from provider-native request/response JSON. Built-in roles and keys:

| `message.role` | Stored fields beyond role |
| --- | --- |
| `system` | `content: string or TextContent[]`, `sections?: object<string,string or null>`, `toolsAdded?: Tool[]`, `toolsRemoved?: {name:string}[]`, `timestamp: number` |
| `user` | `content: string or (TextContent or ImageContent)[]`, `timestamp: number` |
| `assistant` | Ordered `content: (TextContent or ThinkingContent or ToolCall)[]`; `api`, `provider`, `model`, `usage`, `stopReason`, `timestamp`; optional `responseModel`, `responseId`, `providerThinkingLevel`, `thinkingLevel`, `diagnostics`, `deferred`, `errorMessage`, `rawStopReason`, `endTurn`, `durationMs` |
| `toolResult` | `toolCallId`, `toolName`, ordered text/image `content`, `isError`, `timestamp`; optional `details`, `usage`, `nestedCalls`, `durationMs` |
| `bashExecution` | `command`, `output`, `exitCode` (writer may omit undefined), `cancelled`, `truncated`, `timestamp`; optional `fullOutputPath`, `excludeFromContext` |
| `custom` | `customType`, string or text/image `content`, `display`, `timestamp`, optional `details` |

`appendMessage` disallows direct `branchSummary` and `compactionSummary` arguments through its public signature; these roles are synthesized from top-level summary entries during replay. Extension declaration merging can add runtime roles beyond the built-ins. [Core message types](https://github.com/badlogic/pi-mono/blob/a4ccccbd64d4ccea1644f5a07bb94ef09075b219/packages/ai/src/types.ts#L559-L667), [coding-agent roles/conversion](https://github.com/badlogic/pi-mono/blob/a4ccccbd64d4ccea1644f5a07bb94ef09075b219/packages/coding-agent/src/core/messages.ts#L26-L196), [append signature](https://github.com/badlogic/pi-mono/blob/a4ccccbd64d4ccea1644f5a07bb94ef09075b219/packages/coding-agent/src/core/session-manager.ts#L1209-L1224).

| Content `type` | Literal stored keys |
| --- | --- |
| `text` | `text`, optional `textSignature` |
| `thinking` | `thinking`, optional `thinkingSignature`, `redacted` |
| `image` | `data` (base64 image bytes), `mimeType` |
| `toolCall` | `id`, `name`, `arguments` (JSON object), optional `thoughtSignature`, `namespace`, `argumentsError` |

Order of content blocks is meaningful. A tool call belongs inside the assistant block array; results are separate `toolResult` messages linked through `toolCallId`. `argumentsError` can preserve invalid original argument text while `arguments` is `{}`. Text/thinking/thought signatures carry opaque provider replay information. `textSignature` can itself be a JSON-encoded versioned signature string with `v`, `id`, optional `phase` (`commentary` or `final_answer`); do not parse it as ordinary prose. Redacted thinking can retain an encrypted signature. The core union here contains image, text, thinking and calls; it declares no native audio/video content block. Extensions may retain other media within their own opaque data. [Block types](https://github.com/badlogic/pi-mono/blob/a4ccccbd64d4ccea1644f5a07bb94ef09075b219/packages/ai/src/types.ts#L420-L465).

System messages record instructions and changing tool definitions. Leading content is the base prompt; later content adds instructions. Named `sections` update or remove (`null`) prompt sections in object order. `toolsAdded` provides complete definitions (`name`, `description`, JSON-schema `parameters`, optional `constrainedSampling`); `toolsRemoved` references names. A compaction checkpoint's `systemMessage` contains the effective full prompt and tool state, with timestamp reset to the compaction time. These fields are necessary to reproduce current context. [System semantics](https://github.com/badlogic/pi-mono/blob/a4ccccbd64d4ccea1644f5a07bb94ef09075b219/packages/ai/src/types.ts#L559-L585), [tool fields](https://github.com/badlogic/pi-mono/blob/a4ccccbd64d4ccea1644f5a07bb94ef09075b219/packages/ai/src/types.ts#L775-L788), [checkpoint writer](https://github.com/badlogic/pi-mono/blob/a4ccccbd64d4ccea1644f5a07bb94ef09075b219/packages/coding-agent/src/core/session-manager.ts#L1280-L1295).

## Usage, diagnostics, nested tools and time

`Usage` stores numbers `input`, `output`, `cacheRead`, `cacheWrite`, `totalTokens`, optional `cacheWrite1h`, `reasoning`; `cost` contains `input`, `output`, `cacheRead`, `cacheWrite`, `total`, optional boolean `totalFromProvider`. `reasoning` is a subset of output; `cacheWrite1h` is a subset of cacheWrite. `cost.total` may be provider billed cost or the catalog estimate; `totalFromProvider` marks provider totals. Preserve per-occurrence usage wherever it appears: assistant messages, tool results, summaries, separate usage records. Summing all scopes without an accounting policy risks counting the same work more than once. [Usage declaration](https://github.com/badlogic/pi-mono/blob/a4ccccbd64d4ccea1644f5a07bb94ef09075b219/packages/ai/src/types.ts#L467-L495).

`diagnostics[]` uses `type`, `timestamp`, optional `error` (`name?`, `message`, `stack?`, `code?: string or number`) and JSON-object `details?`. Its timestamp is generated by `Date.now()`. `deferred` uses `provider`, `modelId`, `api`, `id`, optional `expiresAt`, `pollAfterMs`, `data`; retain provider conversion data. `nestedCalls` contains `calls[]` and `complete`; each nested call has `id`, `name`, optional `arguments`, `argumentsBytes`, `durationMs`, `error`, and `status: ok|error|unfinished`. Nested results are deliberately absent and bounds can omit argument bodies. [Diagnostics](https://github.com/badlogic/pi-mono/blob/a4ccccbd64d4ccea1644f5a07bb94ef09075b219/packages/ai/src/utils/diagnostics.ts#L3-L42), [deferred](https://github.com/badlogic/pi-mono/blob/a4ccccbd64d4ccea1644f5a07bb94ef09075b219/packages/ai/src/types.ts#L547-L557), [nested calls](https://github.com/badlogic/pi-mono/blob/a4ccccbd64d4ccea1644f5a07bb94ef09075b219/packages/ai/src/types.ts#L626-L664).

| Location | Time representation |
| --- | --- |
| Header and entry `timestamp` | UTC ISO-8601 string, millisecond precision for current writer |
| Any built-in nested message `timestamp` | Unix epoch milliseconds; assistant value records request start, tool-result value creation time |
| Compaction `systemMessage.timestamp` | Unix epoch milliseconds derived from outer compaction ISO timestamp |
| Synthesized summary/custom message timestamp | Milliseconds derived from outer ISO timestamp |
| `diagnostics[].timestamp` | Unix epoch milliseconds |
| Assistant/tool-result/nested-call `durationMs` | Elapsed milliseconds measured with a monotonic clock, not epoch time |
| `deferred.pollAfterMs` | Millisecond delay by field naming; `expiresAt` unit unspecified at reviewed interface |
| Arbitrary custom/details/deferred data | Application/provider defined; preserve exact values |

The outer append timestamp and nested request timestamp represent different moments. Never sort the tree by either timestamp to reconstruct native storage order. [Message timestamps/durations](https://github.com/badlogic/pi-mono/blob/a4ccccbd64d4ccea1644f5a07bb94ef09075b219/packages/ai/src/types.ts#L584-L664), [derived timestamps](https://github.com/badlogic/pi-mono/blob/a4ccccbd64d4ccea1644f5a07bb94ef09075b219/packages/coding-agent/src/core/messages.ts#L100-L137).
