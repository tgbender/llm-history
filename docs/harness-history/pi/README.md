Pi stores a UTF-8 JSONL file per session. The first parsed record is a session header; subsequent records form an append-only tree with `id`/`parentId`. Physical file order retains abandoned branches, labels, state, context edits and usage. Effective model context is a selected root-to-leaf path with compaction and context edits applied. A provider request or rendered chat is a derived view. [Reader](https://github.com/badlogic/pi-mono/blob/a4ccccbd64d4ccea1644f5a07bb94ef09075b219/packages/coding-agent/src/core/session-manager.ts#L617-L670), [projection](https://github.com/badlogic/pi-mono/blob/a4ccccbd64d4ccea1644f5a07bb94ef09075b219/packages/coding-agent/src/core/session-manager.ts#L390-L584).
