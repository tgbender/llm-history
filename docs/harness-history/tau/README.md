# Hugging Face Tau native history

Reviewed 2026-11-07 against the **Python [`huggingface/tau`](https://github.com/huggingface/tau)** implementation, branch `main`, release **v0.4.9**, commit [`47610d3ed71deb70b07443a8641588ffc9c8ffc6`](https://github.com/huggingface/tau/commit/47610d3ed71deb70b07443a8641588ffc9c8ffc6), committed 2026-11-03. Tau's repository describes its `tau_ai` / `tau_agent` / `tau_coding` layers and Pi-inspired architecture. This document covers that implementation. [Repository](https://github.com/huggingface/tau/blob/47610d3ed71deb70b07443a8641588ffc9c8ffc6/AGENTS.md#L1-L35).

Tau persists a JSONL stream of strict discriminated entry models. Outer entry keys use **snake_case**, outer timestamps are **Unix seconds**, and nested Pi-compatible messages/usage use **camelCase aliases** and **Unix milliseconds**. The transcript has no mandatory session header or top-level format-version record. Separate project/global indexes hold session identity, title and discovery metadata; archive indexes hold visibility state. These distinctions are essential for a faithful capture. [Entry models](https://github.com/huggingface/tau/blob/47610d3ed71deb70b07443a8641588ffc9c8ffc6/src/tau_agent/session/entries.py#L15-L144), [nested wire models](https://github.com/huggingface/tau/blob/47610d3ed71deb70b07443a8641588ffc9c8ffc6/src/tau_agent/messages.py#L14-L56), [index model](https://github.com/huggingface/tau/blob/47610d3ed71deb70b07443a8641588ffc9c8ffc6/src/tau_coding/session_manager.py#L56-L120).

## Evidence and confidence

High confidence: reviewed actual Pydantic models, canonical JSONL codec, storage writer, state replay, tree helper, coding-session branch/repair persistence, index/archive manager, paths, and exporter. Corroborating upstream tests were inspected: [canonical naming, timing, images, migration](https://github.com/huggingface/tau/blob/47610d3ed71deb70b07443a8641588ffc9c8ffc6/tests/test_session.py#L39-L322), [strict errors and file storage](https://github.com/huggingface/tau/blob/47610d3ed71deb70b07443a8641588ffc9c8ffc6/tests/test_session.py#L323-L471), [labels and compaction boundary variants](https://github.com/huggingface/tau/blob/47610d3ed71deb70b07443a8641588ffc9c8ffc6/tests/test_session.py#L472-L857), [archive behavior](https://github.com/huggingface/tau/blob/47610d3ed71deb70b07443a8641588ffc9c8ffc6/tests/test_session_manager.py#L381-L437), [durable tool repair](https://github.com/huggingface/tau/blob/47610d3ed71deb70b07443a8641588ffc9c8ffc6/tests/test_coding_session.py#L1005-L1230). The upstream suite was not executed for this documentation-only review.

Limits: JSON values in custom namespaces, tool `details`, diagnostics and provider signatures are intentionally open payloads. Provider-specific opaque schemas need the matching adapter/extension version. No general cross-harness import contract or transcript-pruning API was established by this targeted source review. This specification describes the pinned release's accepted/stored protocol and its explicit legacy migrations.
